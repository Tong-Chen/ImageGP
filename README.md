# ImageGP

[![](https://zenodo.org/badge/351442846.svg)](https://doi.org/10.5281/zenodo.21711936)

This is the core code of ImageGP (new version <https://www.bic.ac.cn/BIC>, old version <https://www.bic.ac.cn/ImageGP/>) web site.


## Install

### Install from GitHub

Github: https://github.com/Tong-Chen/ImageGP

```
install.packages("pak")
pak::pak("git::https://github.com/Tong-Chen/ImageGP")
```

or

```
# install.packages("devtools")
devtools::install_github("Tong-Chen/ImageGP")
```

or

```
install.packages("remotes")
remotes::install_github("Tong-Chen/ImageGP")
```

### Install from Gitee

Gitee: https://gitee.com/ct5869/ImageGP

```
install.packages("pak")
pak::pak("git::https://gitee.com/ct5869/ImageGP")
```

or

```
# install.packages("devtools")
devtools::install_git("https://gitee.com/ct5869/ImageGP")
```

or

```
install.packages("remotes")
remotes::install_git("https://gitee.com/ct5869/ImageGP")
```
